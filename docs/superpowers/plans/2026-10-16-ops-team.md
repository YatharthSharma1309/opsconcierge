# OpsConcierge team and hackathon cleanup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the August 2026 XPRIZE submission layer and add four project skills (Builder, Customer finder, UI scout, Competitor analyst) that stay in this repo.

**Architecture:** Delete the public `/api/health/xprize` route and the submission docs, then strip hackathon wording from the product UI and the docs that still describe Gemini, Firebase, and the two lanes. Add one `SKILL.md` per role under `.agents/skills/` and a short router in `AGENTS.md`. Skills load only when a request matches their description.

**Tech Stack:** Next.js 16, Playwright smoke tests, Markdown skills in `.agents/skills/`, `AGENTS.md`.

## Global Constraints

- Support routes and hiring routes stay.
- `GET /api/health` stays. It checks Postgres only (`status`, `database`, `timestamp`).
- Gemini, OpenRouter, Firebase Realtime Database writes, and execution-run tables stay.
- A missing price, email, or quote is written as `not published`. Nothing is invented.
- No skill sends email, posts, or contacts anyone.
- The Builder does not remove the support lane or the hiring lane.
- The Customer finder lists a company only when a public page shows the fit.
- The UI scout recommends for a named screen and does not restyle the app unless the user then asks the Builder to.
- The Competitor analyst records the page URL and the date seen.
- Do not run a competitor, customer, or UI research pass in this plan.
- Do not add billing or a new agent lane.
