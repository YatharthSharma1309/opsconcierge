# Name research (23 Oct 2026)

**Selected name: Penaven.**

Checked the same evening against the public registries this note can reach. `penaven.com`, `penaven.in`, and `penaven.io` are unregistered (Verisign, NIXI, and Identity Digital RDAP each returned 404). A quoted web search found no live software product under Penaven. The wordmark on the screens is Penaven. The repository, the public host, and the **$39/month** price stay as they are. Founder talks stay at 0.

Lindwell is dropped. `lindwell.com` is an aftermarket listing, and Lindywell is a live Pilates app. Names already offered for sale were not used.

Deskora was the outside recommendation. It is closed: [deskora.de](https://www.deskora.de/en/) is a Windows desktop organizer, deskora.com is already registered, and Deskera is a separate business-software brand.

## What a name has to do

- Sound like software a 5–50 person team would trust with customer conversations and a hiring shortlist.
- Leave room for support, tickets, knowledge, and hiring.
- Stay clear of helpdesk brands already in the market (Zendesk, Freshdesk, Intercom, Gorgias, Front, Help Scout, Crisp, Tidio, Chatbase, Pylon, Plain).
- Stay clear of the fictional rehearsal companies in [`PROSPECT_PRACTICE.md`](./PROSPECT_PRACTICE.md): Northline, Clearledger, Dockline, Rosterly, Fieldnote, Deskform, Ledgerlane.
- Avoid the `-ora` ending. It sits next to Deskora and Deskera.

The tagline stays with the product, whichever wordmark is eventually used: **Answers from your docs. A person when it isn’t.**

## The name

**Penaven.** Said as “pen-a-ven.”

The pen is the tool on the desk: the answer written from the docs, and the note a person picks up when the docs do not cover it. The same word can hold a hiring note. The letters alternate, so the wordmark stays open. It does not sit next to Deskora, Deskera, Zendesk, or Freshdesk.

Tagline stays: **Answers from your docs. A person when it isn’t.**

Category line: support desk for small teams.

## What is still outside this check

RDAP says the domains are unregistered. It does not file a trademark. Before Penaven is printed on the live site, the team records the result of:

1. [IP India public search](https://www.ipindia.gov.in/trade-marks-before-you-apply-search-existing-trademarks) for PENAVEN, class 9 and class 42.
2. [USPTO trademark search](https://tmsearch.uspto.gov/) for the same word.
3. A registrar lookup for `penaven.app`, which did not answer in this pass.

Do not buy a domain from this note. Do not revive Deskora or Lindwell.
